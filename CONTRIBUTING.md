# Contributing to PairDesk

Thanks for helping. PairDesk is a small MIT-licensed remote-desktop app from KnowReva.

- **Bugs and ideas:** open an issue. Say which PairDesk version (`pairdesk --version`), which distribution,
  and what you expected to happen.
- **Security problems:** please don't open a public issue. See [SECURITY.md](SECURITY.md).
- **Changes:** fork, make one focused change per pull request, and run the tests first:
  `make check`. Keep the plain, short style of the existing help text and messages.
- **Never include** real computer names, addresses, user names or keys in code, tests, screenshots or
  logs you attach.

By sending a pull request you agree that your change is released under the [MIT licence](LICENSE).
